# Music Tango 用户手册

版本 1.0.1.1 · [English](USER_MANUAL.md) · 简体中文 · [繁體中文](USER_MANUAL.zh-TW.md)

Music Tango 可以播放本地音乐、收听网络电台、显示同步歌词，并能下载音乐。它还能把电台中的人声实时转换为字幕，整个识别过程完全在手机上完成。

## 1. 开始使用

**系统要求：** Android 8.0 或更高版本。实时字幕功能需要性能较好的手机，并需要几百 MB 的可用空间来存放语音模型。

首次打开 Music Tango 时：

1. 系统询问时，请**允许访问音乐和音频**。应用需要此权限才能找到设备上的歌曲。
2. **允许通知**，这样播放控件才会显示在通知栏和锁屏上。
3. 曲库一开始是空的。请按照[建立曲库](#3-建立曲库)添加歌曲。

---

## 2. 界面导览

屏幕底部的导航栏有五个标签页：

| 标签页 | 内容 |
|--------|------|
| **首页** | 歌曲库、搜索，以及“扫描本地音乐” |
| **播放列表** | 你的播放列表 |
| **电台** | 已保存的电台 |
| **浏览器** | 音乐下载器 |
| **设置** | 应用偏好设置 |

播放时，导航栏上方会出现**迷你播放器**：

- 点按迷你播放器可打开完整的**正在播放**界面。
- 使用其中的播放/暂停按钮，可以在不离开当前界面的情况下暂停或继续播放。
- 在迷你播放器中打开**队列**，可以查看接下来要播放的歌曲。

## 3. 建立曲库

### 扫描音乐

1. 在**首页**打开菜单，选择**扫描本地音乐**。如果曲库为空，该按钮会直接显示在屏幕上。
2. 选择扫描范围：
   - **扫描设备**：搜索 Android 系统中登记的所有音频文件。
   - **选择文件夹**：选择一个文件夹（例如 SD 卡上的文件夹），只扫描该文件夹。
3. 扫描结果会显示找到的文件数量。已在曲库中的歌曲会标记为**已在曲库**。
4. 使用**排序**，可按**名称**、**艺人名称**或**最后修改**时间升序或降序排列。搜索框可按名称或艺人筛选结果。
5. 勾选需要的歌曲，或使用**全选**，然后点按**添加已选**。

### 搜索和管理歌曲

- **首页**的搜索会匹配歌曲名、艺人、专辑和文件路径。
- 点按歌曲即可播放。
- 点按歌曲的**更多**（⋮）按钮，可以：
  - **加入队列**，排在当前歌曲之后
  - **添加到播放列表**
  - **编辑元数据**，修改应用中显示的歌曲名、艺人或专辑
  - **从曲库移除**。这只会把歌曲从 Music Tango 中移除，音频文件仍保留在设备上。

---

## 4. 播放音乐

音乐会在后台持续播放。你可以通过通知栏、锁屏、蓝牙耳机和车载系统控制播放。

### 播放模式

点按**播放模式**按钮，可在三种模式之间循环切换：

| 模式 | 效果 |
|------|------|
| **列表循环** | 按顺序播放队列，播完后从头开始（默认） |
| **单曲循环** | 重复播放当前歌曲 |
| **随机播放** | 随机顺序播放队列 |

### 播放队列

从迷你播放器或“正在播放”界面打开队列。在队列中你可以：

- 点按歌曲，直接跳到该歌曲。
- **长按并拖动**歌曲来调整顺序。
- 点按 **✕** 把歌曲移出队列。
- 使用**清空队列**清空整个队列。

---

## 5. “正在播放”界面

“正在播放”界面把歌曲显示在一张旋转的黑胶唱片上，并提供进度条、上一首/下一首、播放/暂停和播放模式按钮。

- **更换唱臂：** 点按唱臂的转轴，可以选择样式：默认、黑色、金色、现代、复古、蒸汽朋克或赛博朋克。
- **更换封面：** 点按封面打开封面菜单，然后：
  - **从设备选择文件**
  - **使用图片网址**，粘贴图片链接
  - **搜索谷歌图片**，在网上搜索后点按**设为封面**
  - **清除此歌曲的缓存**，恢复为自动获取的封面
- **歌词：** 当前歌词行显示在唱片下方，点按即可打开完整歌词界面。

## 6. 歌词

歌曲开始播放时，Music Tango 会根据歌曲名、艺人和专辑查找同步歌词（LRC）。找到的歌词会被保存，之后离线也能查看。

在歌词界面中：

- 当前歌词行会高亮显示，并随音乐自动滚动。
- 点按某一行的 **▶** 即可**从此处播放**，歌曲会跳到该行。
- 使用 **A− / A+** 缩小或放大歌词文字。
- 如果没有找到歌词，或歌词不正确：
  - **导入歌词**：从设备载入 `.lrc` 文件。
  - **粘贴或输入歌词**：手动输入或粘贴歌词，可以是纯文本，也可以是带 `[mm:ss.xx]` 时间标签的 LRC 格式。

歌词存储文件夹和默认字号可在[设置 → 歌词](#歌词)中修改。

---

## 7. 播放列表

打开**播放列表**标签页。

- **创建播放列表：** 点按 **+** 并输入名称。
- **打开播放列表：** 点按它。在播放列表中你可以：
  - **播放此列表**，从第一首开始播放；或点按某首歌，从该歌曲开始播放
  - **添加歌曲**：搜索曲库，勾选歌曲，然后点按**添加**
  - **移除**歌曲
  - 使用**上移 / 下移**调整歌曲顺序
- 通过播放列表的菜单可以**重命名**或**删除**播放列表。删除播放列表不会删除任何歌曲。
- 使用**导出 / 导入**分享播放列表，或把它转移到另一台设备。

## 8. 电台

打开**电台**标签页可以看到已保存的电台。点按电台即可开始收听。直播流会显示**直播**标记，无法拖动进度。

### 添加电台

- **搜索电台：** 在免费的 Radio Browser 电台目录中按名称搜索，然后点按结果旁的**添加**。
- **添加电台：** 手动输入**电台名称**和**串流网址**（例如 `.mp3`、`.aac` 或 `.m3u8` 串流链接）。

要移除电台，请在电台菜单中选择**删除电台**。

## 9. 电台实时字幕

Music Tango 可以为电台中的语音节目（如新闻、谈话节目和播客）显示实时字幕。它使用 Whisper 语音识别模型，在手机上本地运行，不会上传任何音频。

### 第 1 步：获取模型

1. 进入**设置 → 字幕生成 → 下载模型**。
2. 选择一个模型并点按**下载**，然后点按**使用**将其设为当前模型。

| 模型 | 大小 | 说明 |
|------|------|------|
| Tiny | 约 75 MB | 最快，适合较旧的手机 |
| Base | 约 142 MB | 准确度更高 |
| Small（量化版） | 约 183 MB | 接近 Small 的准确度，体积更小 |
| Small | 更大 | 准确度最高，速度最慢 |

- **英语**模型只能识别英语，但对英语的识别略准确一些。
- **多语言**模型会自动检测所说的语言，支持中文。

如果你已经有 GGML/GGUF 格式的 Whisper 模型文件，也可以在 **Whisper 模型文件**下使用**选择文件**。使用**测试模型**可以检查模型能否正常加载。

### 第 2 步：为电台开启字幕

在**电台**标签页中，打开电台的菜单并选择**开启实时字幕**。已开启字幕的电台会高亮显示。

### 第 3 步：收听

播放该电台，然后打开**正在播放**或歌词界面。识别出的语音会以字幕形式显示。状态行会显示当前进度：

- *正在连接电台* / *正在解码电台音频*
- *正在生成字幕（N 秒音频）*
- *正在收听，尚未检测到语音*（播放音乐时属于正常现象）

**提示**

- 第一条字幕通常需要几秒钟才会出现。
- 如果字幕比声音早或晚，请调整**设置 → 字幕生成 → 电台字幕延迟**。
- 屏幕关闭时字幕生成会暂停，重新打开屏幕即可继续。
- 字幕生成会占用大量处理器资源和电量，较小的模型耗电更少。

## 10. 下载音乐

打开**浏览器**标签页，里面有两种下载器。

### API 下载器

1. 在**搜索歌曲…**中输入歌曲名。
2. 打开**搜索设置**选择：
   - **来源**：网易云音乐、QQ 音乐、酷我、Tidal、Qobuz、JOOX、哔哩哔哩、Apple Music、YouTube Music 或 Spotify
   - **比特率**：从 128K 标准（每首歌小于 3 MB）到 24bit 无损（每首歌大于 50 MB）
3. 点按结果上的**下载**。标记为*链接不可用*的结果无法从当前来源下载，请换一个来源试试。

### 浏览器下载器

内置的网页浏览器。在**搜索或输入 URL**中输入网址或搜索词，浏览到包含音频文件的网页。开始下载时，应用会询问保存位置。**地址历史**可以找回之前访问过的网页。

### “另存为”对话框

保存文件之前，你可以：

- 修改**文件名**。应用不接受文件名中不允许使用的字符。
- 选择**保存到艺人文件夹**。
- 选择**保存位置**：默认的 **Music** 文件夹或你选择的文件夹。

如果已存在同名文件，可以选择**覆盖**或**重命名**。

下载的歌曲会自动加入曲库。

### 队列、历史和文件夹

在**浏览器操作**（⋮）中：

- **下载队列**：显示正在进行的下载。
- **下载历史**：列出以往的下载，以及每次下载是否成功。
- **下载文件夹**：更改文件的保存位置。可以选择 SD 卡上的文件夹，应用重启后仍会保留访问权限。

> 请只下载你有权下载的音乐。

## 11. 设置

### 主题
**跟随系统**、**浅色**或**深色**。在 Android 12 及以上版本中，界面颜色会跟随壁纸变化。

### 语言
**跟随系统**、**English**、**简体中文**或**繁體中文**。

### 歌词
- **歌词存储文件夹：** 歌词文件的保存位置。**使用默认值**会把歌词保存在应用内部。
- **默认歌词字号**
- **清除缓存：** 删除已保存的歌词，之后会重新下载。

### 封面
- **封面缓存文件夹：** 下载的封面图片的保存位置。卸载应用时，默认的应用文件夹会被删除。如果想保留封面，请选择其他文件夹。

### 字幕生成
- **Whisper 模型文件 / 下载模型：** 参见[电台实时字幕](#9-电台实时字幕)。
- **电台字幕延迟：** 调整字幕时间，使其与声音对齐。

---

## 12. 数据备份

进入**设置 → 数据备份**。

- **导出数据**：把曲库、播放列表、歌词缓存、下载历史和电台保存到你选择的文件中。
- **导入数据**：从备份文件恢复。

> **警告：** 导入备份会*替换*本设备上当前的全部应用数据。

备份中只包含应用的记录，不包含音频文件本身。如果在另一台手机上恢复，那台手机上也需要有这些歌曲。

## 13. 常见问题

| 问题 | 解决方法 |
|------|----------|
| 扫描时找不到歌曲 | 在 Android 设置 → 应用中确认 Music Tango 拥有音乐和音频权限。也可以使用**选择文件夹**直接选择歌曲所在的文件夹。 |
| 歌词错误或缺失 | 使用**导入歌词**或**粘贴或输入歌词**。用**编辑元数据**检查歌曲名和艺人是否正确。 |
| 电台无法播放 | 串流可能已离线或网址已变更。请用**搜索电台**重新查找该电台。 |
| “播放已启用字幕生成的电台前，请先在设置中选择 Whisper 模型文件。” | 在**设置 → 字幕生成 → 下载模型**中下载模型并点按**使用**。 |
| “无法加载 Whisper 模型” | 模型文件可能不完整，或不是 Whisper GGML/GGUF 模型。请删除后重新下载，或换用较小的模型。 |
| “此设备或语言暂不支持离线字幕” | 你的设备可能不支持该模型。请尝试较小的模型，例如 **Tiny**。 |
| 关闭屏幕后字幕停止 | 这是正常现象，重新打开屏幕即可继续。 |
| 字幕与声音不同步 | 在设置中调整**电台字幕延迟**。 |
| 下载失败 | 换一个**来源**或更低的**比特率**。检查下载文件夹是否仍可访问，必要时重新选择。 |
| 通知栏中没有播放控件 | 在 Android 设置中允许 Music Tango 发送通知。 |
