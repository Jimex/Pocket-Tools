# Tango 输入法

**[English](README.md) | 中文**

Tango 输入法（Tango Board）是一款离线优先的 Android 输入法（IME），支持
**英文**、**拼音**、**五笔** 输入，具备拼音/五笔混合输入、本地学习功能，
以及可选的 AI 写作助手。


## 功能特性

- **英文输入** — QWERTY 键盘布局、单词自动补全、编辑距离为 1 的纠错
  （以候选形式提供，按空格不会自动纠错）、下一词预测，以及基于词频/上下文的
  候选词排序。
- **拼音输入** — 全拼、无需声调的整句输入、11 条可选模糊音规则（如
  `z`/`zh`、`n`/`l`、`an`/`ang`）、简体/繁體切换，以及全角中文标点。
- **五笔输入** — 五笔 86 版编码查询、一级简码、全码候选始终排在更长编码之前、
  码满上屏、`z` 拼音反查（标注五笔编码）、`z` 万能键，以及简入繁出。
- **拼音 + 五笔混合输入** — 可选同时给出另一种中文输入法的候选（打五笔时的
  拼音音节，或打拼音时的五笔编码），排在当前模式自身的候选之后。
- **自定义词组与词库** — 添加自己的词组和快捷编码（编码自动建议），或在后台
  导入词表，格式说明见 [docs/user-manual.zh-CN.md](docs/user-manual.zh-CN.md)。
- **本地学习** — 你选过的词会逐渐排到更靠前的位置；学习数据只保存在本机，
  可关闭或清除，并在密码/PIN/敏感输入框中自动禁用。
- **AI 写作工具**（默认关闭）— 校对、改写、语气调整、扩写/精简、翻译、
  从头撰写草稿的写作助手，以及自定义提示词操作，支持流式输出与撤销。
  可对接远程的 OpenAI 兼容接口，也可使用本机模型（LiteRT-LM 或
  llama.cpp/GGUF），且与核心输入法进程相互隔离。
- **使用体验** — 长按或上滑输入按键符号、表情面板、数字输入框自动显示数字键盘、
  多种主题、可调键盘高度与间距、数字行，以及单手模式。
- **隐私优先设计** — 输入法核心进程（`:ime`）不依赖任何网络能力；AI
  相关功能运行在独立的进程/模块中，通过明确的 IPC 边界通信。用户输入
  的文本不会被写入日志。
