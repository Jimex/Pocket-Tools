## 安装步骤

1. 安装 Tango Board 应用（APK 安装包，或未来上架应用商店后从商店安装）。
2. 打开 **Tango Board** 应用。若键盘尚未启用，设置页顶部会显示
   **探戈键盘尚未启用**——点击 **在系统设置中启用**，打开 **Tango Board**。
   - 也可以手动前往：**设置 → 系统 → 语言和输入法 → 屏幕键盘 → 管理键盘**
     （具体路径因厂商而异）。
3. 系统会提示输入法可以读取你输入的文字。这是所有输入法的标准提示，
   阅读后确认即可。
4. 回到应用，如果卡片显示 **探戈键盘不是你当前使用的键盘**，点击
   **切换键盘** 并选择 **Tango Board**。之后也可随时通过导航栏的键盘图标切换。

## 键盘概览

按键上方的横条（候选栏）在打字时显示候选词；没有候选时则显示工具按钮：

| 按钮 | 作用 |
|---|---|
| ☰ **键盘功能** | 打开键盘菜单：AI 写作助手（启用 AI 后显示）、表情符号、自定义词组、键盘高度、单手模式、设置。 |
| ✨ **写作工具** | 打开 AI 写作面板（仅在启用 AI 写作后显示）。 |
| 📋 **粘贴** | 粘贴剪贴板中的文字。 |
| **简 / 繁** | 在中文模式下切换简体/繁体候选，按钮显示的是当前使用的字形。 |
| ⚙ **设置** | 打开 Tango Board 设置。 |

显示候选时：

- **⌄ 显示全部候选词**：展开为可滚动的候选网格。
- **✕ 不再建议**：隐藏预测，直到你再次输入。

## 切换输入模式

- **中/英 键**（位于 `123` 旁）——点击在英文与首选中文输入（默认拼音）之间切换。
- **长按 中/英** 可直接选择英文、拼音或五笔。
- **设置 → 语言 → 输入模式** 决定该键可以切换到哪些模式（英文始终可用）；
  **首选中文输入方式** 决定点击时切换到拼音还是五笔。
- **简/繁**——使用候选栏上的 简/繁 按钮，或在 **设置 → 语言 → 字符** 中选择
  简体、繁體或两者皆可。

## 英文输入

在 QWERTY 布局上正常输入：

- 候选栏会随输入显示补全和纠错，例如输入 `wor` 可能出现 `world`、`word`、
  `work`。点击即可替换已输入的内容。
- 空格按原样提交你输入的内容。Tango Board **不会**在按空格时自动纠错，
  纠错只作为候选供你选择。
- 输完一个词后，候选栏会建议可能的下一个词。
- **Shift**：点一次输入一个大写字母，再点一次锁定大写，第三次取消。

## 拼音输入

输入拼音，键盘上方显示正在输入的拼音，候选栏显示对应的字、词和短语：

```text
输入：nihao
候选：你好 | 您好 | 你号
```

- 点击候选即可上屏。词语、短语乃至整句都作为一个整体提交。
- 无需输入声调。
- 连续输入如 `zhongguoren` 会自动切分并组句（`中国人`）。
- **模糊拼音**——在 **设置 → 语言 → 模糊拼音** 中开启需要视为等同的音对，
  默认全部关闭。
  - 音节开头：`z/zh`、`c/ch`、`s/sh`、`n/l`、`f/h`、`l/r`
  - 音节结尾：`an/ang`、`en/eng`、`in/ing`、`ian/iang`、`uan/uang`
- 中文模式下标点自动转为全角中文标点（`，。？！：` 及弯引号）。数字后的 `.`
  保持为小数点，因此 `3.14` 能正确输入。

## 五笔输入

选择五笔（长按 中/英，或将其设为 **首选中文输入方式**），输入五笔编码，
候选栏显示匹配的字词。

- **一级简码**——最常用的 25 个字一键即出。
- **全码优先**——完整输入的编码，其对应字总排在仅以该编码开头的更长编码之前，
  即使你更常用后者。学习和上下文只会在这两组 *内部* 调整顺序。
  （例如 `bn` 总是先出 也，再出 了。）
- **码满上屏**——第四码打完且有候选时，首选自动上屏。无法识别的四码不会作为文字提交。
- **`z` 拼音反查**——以 `z` 开头输入拼音，可查找不会拆的字；每个候选都会标注
  其五笔编码，便于学习。
- **`z` 万能键**——首码之后的 `z` 代表不确定的字根位置（最多两个）。
- **简入繁出**——选择繁体时，照常输入简体五笔编码即可得到繁体输出。

## 拼音 + 五笔混合输入

**设置 → 语言 → 拼音/五笔 混合输入** 开启时（默认开启），键盘还会给出另一种
中文输入法的候选——打五笔时的普通拼音音节，或打拼音时的五笔编码——
排在当前模式自身的候选之后。

> 在同一段连续输入中，前一个字用五笔、后一个字用拼音的混合方式暂不支持——
> 详见 [STATUS.md](STATUS.md)。

## 符号、数字与表情

- **长按字母键** 输入键上的小字提示（第一行为数字，第二行为 `!@#$%&*()`，
  第三行为 `'/-_:;?`）。开启数字行后，第一行的提示会换成其他符号。
- **上滑按键** 可直接输入提示字符，无需长按（可在 **设置 → 打字 → 上滑输入符号** 中关闭）。
- **长按 `.`** 输入 `! ? : ; ' "`。
- **`123`** 打开符号页；**`=\<`** 打开更多符号（货币、数学符号、`©®™✓`、括号）；
  **`ABC`** 返回字母键盘。
- **表情**——☰ → **表情符号**，或长按 `,`。表情按类别分组，并有 **最近使用** 标签页。
- **数字键盘**——在数字和电话号码输入框中，会自动显示计算器式数字键盘（或电话拨号盘）。
  可在 **设置 → 打字 → 数字输入使用数字键盘** 中关闭。

## 自定义词组

添加自己的词语、人名或快捷短语，保存后立即可以打出：

- 在键盘上：☰ → **自定义词组**。
- 在设置中：**设置 → 语言 → 我的词组**。

输入词组和你要打的编码。编码会根据字自动建议（可在 **编码类型** 中选择拼音或五笔），
可随意修改。较短的编码即成为快捷方式；多音字可能需要手动更正。
自定义词组排在内置词库之前。

## 导入词库

导入词表，批量添加专业词汇。

1. 前往 **设置 → 语言 → 已导入的词库 → 导入词库**，选择一个文本文件。
2. 每行包含一个词、可选的编码和可选的权重，用 **制表符或逗号** 分隔。
   以 `#` 开头的行为注释：

   ```text
   # 我的词
   你好	nihao	1000
   中国	zhongguo	850
   软件	ruanjian
   ```

3. 导入在后台进行，期间可以继续打字。完成后会显示词条数量，或显示 **失败** 及原因。
   格式错误的行会被跳过，其余内容照常导入。
4. 每个导入的词库都可以单独启用/停用、设置 **优先级**（与其他词库冲突时优先级高者胜出），
   或删除。

## 学习与建议

在 **设置 → 打字 → 建议与学习** 中：

- **从你的输入中学习**（默认开启）——你选过的词会逐渐排到更靠前的位置。
  学习数据只保存在本机。
- **清除所有学习记录**——删除你用过的词的记录，在下次打开键盘时生效，
  不影响自定义词组和导入的词库。
- 在密码、PIN 码等敏感输入框中输入的内容不会被学习。

## AI 写作工具

AI 写作 **默认关闭**。在 **设置 → AI 写作 → 启用写作工具** 中开启，然后选择
**重写运行位置**：

- **服务器**——任意兼容 OpenAI 的 API。填写 **接口地址**、**模型**（如 `gpt-4o-mini`
  或 `qwen2.5:7b`）和 **API 密钥**（加密保存；Ollama、LM Studio 等本地服务器通常无需密钥）。
  你的草稿会发送到该服务器。
- **本机（LiteRT-LM）**——手机上的 `.litertlm` 或 `.task` 模型文件。可通过 **选择文件…**
  选取，或粘贴直接下载链接后点击 **下载**。可选 **GPU 加速**、**推理模式** 和 **系统提示词**。
  草稿不会离开设备。
- **本机（llama.cpp）**——通过 **选择文件…** 选取 GGUF 模型文件，可选 **系统提示词**。

本机模型需要 arm64 手机，约占 0.5–2 GB 存储空间和同等内存；速度和效果都不如优质的服务器。

### 使用写作工具

- 点击候选栏上的 ✨ **写作工具**。它处理输入框中已有的文字；若输入框为空，
  则使用剪贴板中的文字（显示 **来自剪贴板**）。
- 想从头写一段草稿，使用 ☰ → **AI 写作助手**：在面板中写好内容，再对其执行操作。
- 内置操作：**校对**、**改写**、**亲切**、**专业**、**扩写**、**精简**、**加表情**、
  **→ English**、**→ 中文**。
- 结果以预览形式流式显示。点击 **编辑** 可修改结果；开启 **基于结果继续** 可对结果
  继续执行其他操作；点击 **✓ 使用此结果** 将其写入输入框。**撤销重写** 可恢复原文。
- **管理操作**（在 AI 写作设置中）可选择显示哪些操作，拖动排序，或恢复默认顺序。
- **自定义提示词**——写下你自己的指令，它会成为面板中的一个按钮。每个提示词可设置
  标签，并可单独指定系统提示词，或选择不使用系统提示词。

写作工具不会出现在密码等敏感输入框中。

## 外观与布局

在 **设置 → 外观** 中：

- **应用语言**——跟随系统、English 或 简体中文。设置页立即生效，键盘在其进程下次重启时生效。
- **主题**——跟随系统、浅色、深色、海洋、花语（下次打开键盘时生效）。
- **按键间距**、**行间距**、**数字行**。
- **单手模式**——关闭、左手、右手，宽度可调。也可通过 ☰ → **单手模式** 循环切换。

在 **设置 → 打字** 中：**按键震动**、**长按延迟**、**上滑输入符号**，以及数字键盘选项。

**键盘高度**——☰ → **键盘高度**，拖动调整后点击 **完成**（或 **重置**）。

**设置 → 恢复默认设置** 可将所有设置还原。

## 隐私说明

- 打字功能完全离线——英文、拼音、五笔、学习、自定义词组和导入的词库均无需联网。
- 只有使用 **服务器** 后端的 AI 写作会发送文字，且仅在你执行操作时发送。
  本机后端不会让文字离开手机。
- 在密码、PIN 码等敏感输入框中输入的内容永远不会被学习、记录或发送给 AI。

## 常见问题排查

- **键盘不显示**——打开 Tango Board 应用，顶部的状态卡片会告诉你是否还需要启用或选择键盘。
- **更新后键盘被切换回其他输入法**——部分设备在重新安装后会重置默认输入法，
  重新选择 Tango Board 即可。
- **浏览器地址栏或部分搜索框没有候选**——这些输入框会要求系统"不提供建议"，
  对所有输入法都会关闭预测，属正常现象。
- **清除学习记录后候选不够贴合**——属正常现象，排序会随你的输入逐渐重建。
- **键盘界面语言没有变化**——键盘会在其进程下次重启时应用新的语言（例如切换一次输入法或重启手机）。
- **找不到写作工具按钮**——确认已开启 **启用写作工具**，且当前不在密码等敏感输入框中。
- **写作工具报错**——错误信息会说明如何处理：添加接口地址、检查 API 密钥、
  等待限流结束、检查模型文件，或在设备无法运行时换用更小的模型或服务器。
