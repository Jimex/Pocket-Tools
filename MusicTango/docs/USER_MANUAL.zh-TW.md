# Music Tango 使用者手冊

版本 1.0.1.2 · [English](USER_MANUAL.md) · [简体中文](USER_MANUAL.zh-CN.md) · 繁體中文

Music Tango 可以播放本機音樂、收聽網路電台、顯示同步歌詞，也能下載音樂。它還能把電台中的人聲即時轉成字幕，整個辨識過程完全在手機上進行。

## 1. 開始使用

**系統需求：** Android 8.0 或更新版本。即時字幕功能需要效能較好的手機，並需要數百 MB 的可用空間來存放語音模型。

第一次開啟 Music Tango 時：

1. 系統詢問時，請**允許存取音樂和音訊**。應用程式需要此權限才能找到裝置上的歌曲。
2. **允許通知**，這樣播放控制項才會顯示在通知欄和鎖定畫面上。
3. 曲庫一開始是空的。請依照[建立曲庫](#3-建立曲庫)加入歌曲。

---

## 2. 介面導覽

畫面底部的導覽列有五個分頁：

| 分頁 | 內容 |
|------|------|
| **首頁** | 歌曲庫、搜尋，以及「掃描本地音樂」 |
| **播放清單** | 你的播放清單 |
| **電台** | 已儲存的電台 |
| **瀏覽器** | 音樂下載器 |
| **設定** | 應用程式偏好設定 |

播放時，導覽列上方會出現**迷你播放器**：

- 輕觸迷你播放器可開啟完整的**正在播放**畫面。
- 使用其中的播放/暫停按鈕，可以在不離開目前畫面的情況下暫停或繼續播放。
- 從迷你播放器開啟**佇列**，可以查看接下來要播放的歌曲。

## 3. 建立曲庫

### 掃描音樂

1. 在**首頁**開啟選單，選擇**掃描本地音樂**。如果曲庫是空的，該按鈕會直接顯示在畫面上。
2. 選擇掃描範圍：
   - **掃描裝置**：搜尋 Android 系統中登記的所有音訊檔案。
   - **選擇資料夾**：選擇一個資料夾（例如 SD 卡上的資料夾），只掃描該資料夾。
3. 掃描結果會顯示找到的檔案數量。已在曲庫中的歌曲會標示為**已在曲庫**。
4. 使用**排序**，可依**名稱**、**藝人名稱**或**最後修改**時間遞增或遞減排列。搜尋框可依名稱或藝人篩選結果。
5. 勾選需要的歌曲，或使用**全選**，然後輕觸**加入已選**。

### 搜尋和管理歌曲

- **首頁**的搜尋會比對歌曲名稱、藝人、專輯和檔案路徑。
- 歌曲清單上方的標籤可以篩選清單。**最近新增**會把最新加入的歌曲排在前面，並顯示每首歌的新增日期。歌曲設定了分類後，輕觸**全部**或某個分類即可只顯示該分類。篩選可以和搜尋一起使用。
- 輕觸歌曲即可播放。
- 輕觸歌曲的**更多**（⋮）按鈕，可以：
  - **加入佇列**，排在目前歌曲之後
  - **加入播放清單**
  - **編輯中繼資料**，修改歌曲名稱、藝人、專輯或分類
  - **從曲庫移除**。這只會把歌曲從 Music Tango 中移除，音訊檔案仍保留在裝置上。

### 編輯內容會寫入音樂檔案

對於 MP3 和 FLAC 檔案，Music Tango 還會把你編輯的中繼資料（包括分類）和儲存的歌詞寫入音樂檔案本身。重新安裝應用程式或清空曲庫後，再次掃描這些歌曲，編輯內容和歌詞都會恢復。

- 應用程式需要修改檔案時，Android 可能會請你授權。如果你拒絕，或檔案無法安全修改，編輯內容只會儲存在 Music Tango 中，並會有提示告訴你。
- 如果只想把編輯內容儲存在應用程式中，請關閉**設定 → 音樂檔案 → 將編輯內容寫入音樂檔案**。

## 4. 播放音樂

音樂會在背景持續播放。你可以透過通知欄、鎖定畫面、藍牙耳機和車用系統控制播放。

### 播放模式

輕觸**播放模式**按鈕，可在三種模式之間循環切換：

| 模式 | 效果 |
|------|------|
| **清單循環** | 依序播放佇列，播完後從頭開始（預設） |
| **單曲循環** | 重複播放目前歌曲 |
| **隨機播放** | 以隨機順序播放佇列 |

### 播放佇列

從迷你播放器或「正在播放」畫面開啟佇列。在佇列中你可以：

- 輕觸歌曲，直接跳到該歌曲。
- **長按並拖曳**歌曲來調整順序。
- 輕觸 **✕** 把歌曲移出佇列。
- 使用**清空佇列**清空整個佇列。

---

## 5. 「正在播放」畫面

### 歌曲

「正在播放」畫面把歌曲顯示在一張旋轉的黑膠唱片上，並提供進度列、上一首/下一首、播放/暫停和播放模式按鈕。

- **更換唱臂：** 輕觸唱臂的轉軸，可以選擇樣式：預設、黑色、金色、現代、復古、蒸汽龐克或賽博龐克。
- **更換封面：** 輕觸封面開啟封面選單，然後：
  - **從設備選擇文件**
  - **使用圖片網址**，貼上圖片連結
  - **搜索谷歌圖片**，在網路上搜尋後輕觸**設為封面**
  - **清除此歌曲的快取**，恢復為自動取得的封面
- **歌詞：** 目前的歌詞行顯示在唱片下方。輕觸歌詞或向左滑動，即可開啟完整的歌詞頁面。

### 電台

收聽電台時，「正在播放」畫面會顯示電台動畫，而不是黑膠唱片。

- **更換動畫：** 輕觸頂端的調色盤按鈕，可在**音訊波形**和**復古收音機**之間切換。也可以在[設定 → 電台](#電台-1)中選擇。
- 動畫會隨正在播放的聲音變化。如果想省一點電，可以在設定中關閉**跟隨實際音訊**，改為播放裝飾性動畫。
- **直播串流**列取代了進度列，因為直播無法拖曳進度。列尾端的字幕按鈕可以為目前電台開啟或關閉[即時字幕](#9-電台即時字幕)。
- **上一個電台**和**下一個電台**會在已儲存的電台之間切換，到清單末尾後會從頭開始。
- 即時字幕顯示在電台動畫下方。向左滑動可以查看完整字幕紀錄。

## 6. 歌詞

歌曲開始播放時，Music Tango 會根據歌曲名稱、藝人和專輯尋找同步歌詞（LRC）。找到的歌詞會被儲存，之後離線也能查看。

### 歌詞頁面

在「正在播放」畫面向左滑動，或輕觸歌詞，即可開啟歌詞頁面。

- 目前的歌詞行會醒目顯示，並隨音樂自動捲動。
- 輕觸某一行的 **▶** 即可**從此處播放**，歌曲會跳到該行。
- **歌詞選項**（⋮）選單中有：
  - **用 AI 產生歌詞…**：請參閱[下文](#用-ai-產生歌詞)
  - **匯入 LRC 檔案…**：從裝置載入 `.lrc` 檔案
  - **輸入歌詞…**或**編輯歌詞…**：開啟[歌詞編輯器](#編輯歌詞)
  - **字型大小…**：縮小或放大歌詞文字
- 歌曲沒有歌詞時，頁面上會直接提供這些選項。

### 用 AI 產生歌詞

Music Tango 可以聽歌並為你寫出歌詞，整個過程在手機上完成。

1. 選擇**用 AI 產生歌詞…**。
2. 選擇**模型**和歌曲的語言，或選擇**自動偵測**。應用程式會記住你的選擇。
3. 輕觸**產生**。進度顯示在歌詞上方，可以隨時取消。較長的歌曲可能需要幾分鐘。

產生的歌詞第一行會註明是由哪個模型產生的。如果歌曲原本已有歌詞，舊的歌詞檔案會被移到 `archive` 資料夾。

可以選擇兩類模型：

| 模型 | 取得位置 | 適合 |
|------|----------|------|
| **Whisper** | 設定 → 字幕生成 → **下載模型**（與電台即時字幕使用相同的模型） | 支援多種語言，會提供每行的時間 |
| **Fun-ASR** | 設定 → 歌詞 → **歌詞產生模型** | 對演唱歌詞和粵語等中文方言的辨識效果好得多。僅支援中文、英語和日語。約 1.26 GB，首次使用時還會額外準備約 1.5 GB。需要 64 位元手機。每行時間為估算值。 |

演唱的人聲比說話更難辨識，請檢查結果，並在編輯器中修正。

### 編輯歌詞

歌詞編輯器為全螢幕畫面，有兩個分頁：

- **逐行**：列出每一行及其時間。輕觸一行即可選取，然後修改文字，或用 **−0.1s** / **+0.1s** 微調時間。每一行還有**從此行播放**、**在下方插入一行**和**刪除此行**按鈕。使用**新增一行**可在末尾加入新行。
- **LRC 文字**：以純文字顯示歌詞。可以貼上帶有 `[mm:ss.xx]` 時間的 LRC 歌詞，也可以貼上不帶時間的純歌詞。

**讓歌詞與音樂同步。** 播放歌曲，選取一行，在該行開始時輕觸**同步此行**。之後會自動選取下一行，你可以一路輕觸到歌曲結束。**倒退 3 秒**和**快轉 3 秒**可以幫你重新對準某一行。只有目前播放的是這首歌時，這些對時工具才能使用。

**更多編輯選項**（⋮）：

- **平移時間…**：把**選取的行**、**選取的行及之後所有行**或**所有行**提前或延後你輸入的秒數。
- **依時間排序**
- **用 AI 重新對時…**：聽歌後調整能對應上的歌詞行的時間，包括還沒有時間的行。歌詞文字不會改變。
- **顯示波形**：顯示歌曲響度的時間軸，每一行都有一個標記。輕觸標記可選取該行，拖曳選取的標記可修改時間，輕觸其他位置可跳到該處。

**查看**會列出可能的問題：沒有時間的行、無法讀取的時間、順序錯亂的行、重複的行、過長的行，以及超過歌曲結尾的時間。輕觸某個問題即可跳到對應的行。

**復原**和**重做**位於頂端。編輯完成後輕觸**儲存**。如果還有行沒有時間，應用程式會在儲存前詢問，因為這些行在播放時不會顯示。如果未儲存就離開，應用程式會詢問是否捨棄修改。

歌詞儲存資料夾和預設字型大小可在[設定 → 歌詞](#歌詞)中修改。

## 7. 播放清單

開啟**播放清單**分頁。

- **建立播放清單：** 輕觸 **+** 並輸入名稱。
- **開啟播放清單：** 輕觸它。在播放清單中你可以：
  - **播放此清單**，從第一首開始播放；或輕觸某首歌，從該歌曲開始播放
  - **加入歌曲**：搜尋曲庫，勾選歌曲，然後輕觸**添加**
  - **移除**歌曲
  - 使用**上移 / 下移**調整歌曲順序
- 透過播放清單的選單可以**重新命名**或**刪除**播放清單。刪除播放清單不會刪除任何歌曲。
- 使用**匯出 / 匯入**分享播放清單，或把它轉移到另一台裝置。

## 8. 電台

開啟**電台**分頁可以看到已儲存的電台。輕觸電台即可開始收聽。直播串流會顯示**直播**標記，無法拖曳進度。

### 新增電台

- **搜尋電臺：** 在免費的 Radio Browser 電台目錄中依名稱搜尋，然後輕觸結果旁的**添加**。
- **添加電台：** 手動輸入**電台名稱**和**串流網址**（例如 `.mp3`、`.aac` 或 `.m3u8` 串流連結）。

要移除電台，請在電台選單中選擇**刪除電台**。

## 9. 電台即時字幕

Music Tango 可以為電台中的語音節目（如新聞、談話節目和 Podcast）顯示即時字幕。它使用 Whisper 語音辨識模型，在手機上本機執行，不會上傳任何音訊。

### 第 1 步：取得模型

1. 前往**設定 → 字幕生成 → 下載模型**。
2. 選擇一個模型並輕觸**下載**，然後輕觸**使用**將其設為目前模型。

| 模型 | 大小 | 說明 |
|------|------|------|
| Tiny | 約 75 MB | 最快，適合較舊的手機 |
| Base | 約 142 MB | 準確度更高 |
| Small（量化版） | 約 183 MB | 接近 Small 的準確度，檔案更小 |
| Small | 更大 | 準確度最高，速度最慢 |

- **英語**模型只能辨識英語，但對英語的辨識稍微準確一些。
- **多語言**模型會自動偵測所說的語言，支援中文。

如果你已經有 GGML/GGUF 格式的 Whisper 模型檔案，也可以在 **Whisper 模型檔案**下使用**選擇檔案**。使用**測試模型**可以檢查模型能否正常載入。

### 第 2 步：為電台開啟字幕

以下任一方式皆可：

- 在**電台**分頁中，開啟電台的選單並選擇**開啟實時字幕**。已開啟字幕的電台會醒目顯示。
- 電台播放時，輕觸「正在播放」畫面中**直播串流**列尾端的字幕按鈕。字幕關閉時，也可以輕觸電台動畫下方的字幕區域，或在字幕紀錄頁面輕觸**開啟實時字幕**。

電台會短暫重新連線以切換模式。再次輕觸字幕按鈕即可關閉字幕。

### 第 3 步：收聽

播放該電台，然後開啟**正在播放**。辨識出的語音會以字幕形式顯示在電台動畫下方，向左滑動可以查看完整字幕紀錄。狀態列會顯示目前進度：

- *正在連線電台* / *正在解碼電台音訊*
- *正在產生字幕（N 秒音訊）*
- *正在收聽，尚未偵測到語音*（播放音樂時屬於正常現象）

**提示**

- 第一則字幕通常需要幾秒鐘才會出現。
- 如果字幕比聲音早或晚，請調整**設定 → 字幕生成 → 電台字幕延遲**。
- 螢幕關閉時字幕生成會暫停，重新開啟螢幕即可繼續。
- 字幕生成會占用大量處理器資源和電量，較小的模型較省電。
- 與一般播放一樣，其他應用程式播放聲音、接聽電話或拔除耳機時，帶字幕的電台會暫停。

## 10. 下載音樂

開啟**瀏覽器**分頁，裡面有兩種下載器。

### API 下載器

1. 在**搜尋歌曲…**中輸入歌曲名稱。
2. 開啟**搜尋設定**選擇：
   - **來源**：網易雲音樂、QQ 音樂、酷我、Tidal、Qobuz、JOOX、嗶哩嗶哩、Apple Music、YouTube Music 或 Spotify
   - **位元率**：從 128K 標準（每首歌小於 3 MB）到 24bit 無損（每首歌大於 50 MB）
3. 輕觸結果上的**試聽**（播放按鈕）可在下載前先聽一聽。再次輕觸可暫停，拖曳結果下方的進度列可以跳轉。開始試聽時，播放器中正在播放的歌曲會暫停。
4. 輕觸結果上的**下載**。標示為*連結無法使用*的結果無法從目前來源下載，請換一個來源試試。

### 瀏覽器下載器

內建的網頁瀏覽器。在**搜尋或輸入 URL**中輸入網址或搜尋字詞，瀏覽到含有音訊檔案的網頁。開始下載時，應用程式會詢問儲存位置。**地址紀錄**可以找回之前造訪過的網頁。

### 「另存為」對話框

儲存檔案之前，你可以：

- 修改**檔案名稱**。應用程式不接受檔名中不允許使用的字元。
- 選擇**儲存到藝人資料夾**。
- 選擇**儲存位置**：預設的 **Music** 資料夾或你選擇的資料夾。
- 輸入**分類**，或從清單中選擇以前用過的分類。
- 在**加入播放清單**中選擇一個播放清單，下載完成後歌曲會加入該清單。

對話框會記住你上次選擇的分類和播放清單，方便把多首歌下載到同一個地方。

如果已存在同名檔案，可以選擇**覆寫**或**重新命名**。

下載的歌曲會自動加入曲庫。

### 佇列、紀錄和資料夾

在**瀏覽器操作**（⋮）中：

- **下載佇列**：顯示進行中的下載。
- **下載紀錄**：列出以往的下載，以及每次下載是否成功。
- **下載資料夾**：變更檔案的儲存位置。可以選擇 SD 卡上的資料夾，應用程式重新啟動後仍會保留存取權限。

> 請只下載你有權下載的音樂。

## 11. 設定

### 主題
**跟隨系統**、**淺色**或**深色**。在 Android 12 及以上版本中，介面顏色會跟隨桌布變化。

### 語言
**跟隨系統**、**English**、**簡體中文**或**繁體中文**。

### 資料備份
請參閱[資料備份](#12-資料備份)。

### 音樂檔案
- **將編輯內容寫入音樂檔案**（預設開啟）：把編輯後的歌曲名稱、藝人、專輯、分類和儲存的歌詞寫入 MP3/FLAC 檔案。關閉後，編輯內容只會儲存在 Music Tango 中。加入歌曲時，仍會讀取檔案中已有的標籤。請參閱[編輯內容會寫入音樂檔案](#編輯內容會寫入音樂檔案)。

### 歌詞
- **歌詞儲存資料夾：** 歌詞檔案的儲存位置。**使用預設值**會把歌詞存放在應用程式內部。
- **預設歌詞字型大小**
- **清除快取：** 刪除已儲存的歌詞，之後會重新下載。
- **歌詞產生模型：** 下載或刪除[用 AI 產生歌詞](#用-ai-產生歌詞)所用的 Fun-ASR 模型。僅在 64 位元手機上顯示。

### 封面
- **封面快取資料夾：** 下載的封面圖片的儲存位置。解除安裝應用程式時，預設的應用程式資料夾會被刪除。如果想保留封面，請選擇其他資料夾。

### 電台
- **電台動畫：** 電台「正在播放」畫面上顯示**音訊波形**或**復古收音機**。
- **跟隨實際音訊：** 開啟時動畫隨聲音變化；關閉時播放裝飾性動畫，稍微省電一些。

### 字幕生成
- **Whisper 模型檔案 / 下載模型：** 請參閱[電台即時字幕](#9-電台即時字幕)。
- **電台字幕延遲：** 調整字幕時間，使其與聲音對齊。

### 關於
- **版本：** 顯示已安裝的應用程式版本。
- **使用者手冊：** 在應用程式內以目前的應用程式語言開啟本手冊，無需連網。

## 12. 資料備份

前往**設定 → 資料備份**。

- **匯出資料**：把曲庫、播放清單、歌詞快取、下載紀錄和電台儲存到你選擇的檔案中。
- **匯入資料**：從備份檔案還原。

> **警告：** 匯入備份會*取代*本裝置上目前的所有應用程式資料。

備份中只包含應用程式的記錄，不包含音訊檔案本身。如果在另一支手機上還原，那支手機上也需要有這些歌曲。由於編輯內容和歌詞也會寫入 MP3 和 FLAC 檔案，即使沒有備份，這些歌曲也會保留它們。

## 13. 常見問題

| 問題 | 解決方法 |
|------|----------|
| 掃描時找不到歌曲 | 在 Android 設定 → 應用程式中確認 Music Tango 擁有音樂和音訊權限。也可以使用**選擇資料夾**直接選擇歌曲所在的資料夾。 |
| 歌詞錯誤或缺失 | 使用**用 AI 產生歌詞…**、**匯入 LRC 檔案…**或**輸入歌詞…**。用**編輯中繼資料**檢查歌曲名稱和藝人是否正確。 |
| 產生的歌詞不準確 | 演唱的人聲較難辨識。可以改用更大的 Whisper 模型，中文歌曲可以試試 Fun-ASR，然後在歌詞編輯器中修正其餘部分。 |
| 歌詞與歌曲時間對不上 | 開啟**編輯歌詞…**，使用**同步此行**、**平移時間…**或**用 AI 重新對時…**。 |
| 編輯後提示「僅儲存在 MusicTango 中…」 | 無法修改該檔案：授權被拒絕、檔案為唯讀，或其標籤無法安全更新。編輯內容在應用程式中仍然有效。 |
| 「Fun-ASR 需要 64 位元裝置」 | 這支手機無法執行 Fun-ASR，請改用 Whisper 模型。 |
| 電台無法播放 | 串流可能已離線或網址已變更。請用**搜尋電臺**重新尋找該電台。 |
| 「播放已啟用字幕生成的電臺前，請先在設置中選擇 Whisper 模型文件。」 | 在**設定 → 字幕生成 → 下載模型**中下載模型並輕觸**使用**。 |
| 「無法載入 Whisper 模型」 | 模型檔案可能不完整，或不是 Whisper GGML/GGUF 模型。請刪除後重新下載，或改用較小的模型。 |
| 「此設備或語言暫不支持離線字幕」 | 你的裝置可能不支援該模型。請嘗試較小的模型，例如 **Tiny**。 |
| 關閉螢幕後字幕停止 | 這是正常現象，重新開啟螢幕即可繼續。 |
| 字幕與聲音不同步 | 在設定中調整**電台字幕延遲**。 |
| 下載失敗 | 換一個**來源**或更低的**位元率**。檢查下載資料夾是否仍可存取，必要時重新選擇。 |
| 通知欄中沒有播放控制項 | 在 Android 設定中允許 Music Tango 傳送通知。 |
